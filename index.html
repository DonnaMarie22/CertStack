Who carries the stack?

Move from IaaS → PaaS → SaaS and Microsoft manages more of the technical stack.

IaaS

Infrastructure as a Service

YOU: apps, data, runtime, OS
MICROSOFT: hardware + datacenter

Example: Azure Virtual Machines

PaaS

Platform as a Service

YOU: app + data
MICROSOFT: OS, runtime, servers

Example: Azure App Service

SaaS

Software as a Service

YOU: use + configure access
MICROSOFT: application + platform

Example: Microsoft 365

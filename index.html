QUEST 01 // WHAT IS CLOUD COMPUTING?

Rent the computer. Skip the server room.

Cloud computing means getting computing services over the internet instead of owning every piece of physical infrastructure yourself.

OLD SCHOOL DATACENTER
▦BUYBuy the servers
You purchase physical machines up front before you can use the computing power.
▦CONNECTConnect everything
You rack, cable, network, and configure the physical servers so they can communicate and run your systems.
▦MAINTAINMaintain the hardware
You handle power, cooling, repairs, replacements, and the physical upkeep of the equipment.

HOVER OVER A BOX TO SEE WHAT THE OLD WAY REQUIRED

Need more capacity? Buy hardware, install it, power it, cool it, maintain it.

VS
CLOUD
☁

HOVER OR FOCUS A SERVICE FOR A QUICK DEFINITION

The cloud does not remove compute, databases, storage, or networking. It changes how you get them: you request them as services instead of building all the physical infrastructure yourself.

SAME BUILDING BLOCKS // DIFFERENT WAY TO GET THEM

Follow the stack from the first thing you need to the next.

OLD SCHOOL DATACENTERCLOUD
1. COMPUTEBuy a physical server, install it, power it, and keep the machine running.
1
VM / COMPUTECreate a virtual computer in minutes without buying the physical server first.
2. DATABASEInstall database software on your server, configure it, maintain it, and plan for growth.
2
DATABASE SERVICERequest a database service and let the provider handle the physical infrastructure underneath it.
3. STORAGEBuy drives or storage hardware, install them, monitor capacity, and replace failed equipment.
3
CLOUD STORAGEAdd storage when you need it without physically installing new drives.
4. NETWORKBuy switches, routers, cabling, and firewalls, then physically connect and configure everything.

Microsoft's core idea: cloud services include virtual machines, storage, databases, networking, and more. The internet delivers access to those resources, so you can expand without first building another datacenter.

QUEST 04 // CONSUMPTION-BASED MODEL

Buy the machine or pay for the use?

Cloud computing shifts infrastructure spending toward paying for resources as you consume them.

💰

CAPEX

Up-front spending on physical infrastructure such as servers, networking hardware, and datacenter space.

BUY IT
⚡

OPEX

Ongoing spending on services over time. Cloud services are commonly treated as operational expense.

USE IT

TRADITIONAL CAPACITY

Guess too high: wasted capacity. Guess too low: not enough.

CLOUD CAPACITY

Add resources when demand rises. Release them when demand falls.

QUEST 01 // HIGH AVAILABILITY + SCALABILITY

Stay up. Grow when demand grows.

Two different cloud benefits solve two different problems: availabilityAvailability
How often a service is up and usable when people need it. keeps a service accessible, while scalabilityScalability
The ability to add or remove resources so a system can handle changing demand. changes capacity.

♥

HIGH AVAILABILITY

Problem: “What if something fails?”

Goal: Keep the service running and reachable.

Think: STAY ONLINE.
↕

SCALABILITY

Problem: “What if demand changes?”

Goal: Increase or decrease resources to match the workload.

Think: CHANGE SIZE.

VERTICAL SCALING

SMALL VM→BIGGER VM

Give one machine more power, such as more CPU or memory.

HORIZONTAL SCALING

VM→VM + VM + VM

Add more machines or instances to share the work.
